PHP 重大漏洞 php2shell：F5 BIG-IP Advanced WAF 防護說明

PHP 在 2026-10-21 公布兩個可在未登入狀態下遠端執行程式的漏洞。本頁說明使用 F5 BIG-IP Advanced WAF 保護 PHP 網站的客戶，需要完成哪些設定。

第一優先：升級 PHP完整的修補方式是把 PHP 升級到 8.5.12、8.4.27、8.3.36 或 8.2.35。WAF 防護只能在升級完成前降低風險，不能取代升級。

漏洞摘要

  • 攻擊者不需要登入，就可能在網站主機上執行程式，取得 web 服務的權限。
  • 受影響的是處理網頁請求的 PHP，包括 Apache mod_php、PHP-FPM、php-cgi 等。其中 Apache mod_php 的風險最高。
  • PHP 官方已發布修正版。資安研究單位預期攻擊程式會很快公開，建議儘速處理。

F5 Advanced WAF 客戶要完成的 4 件事

F5 已在 K000163821 發布 3 個專用的 attack signature。安裝更新後還要完成下列設定，WAF 才會真正阻擋。

  1. 安裝特徵碼更新（ASU）20261021_191526 或更新版本 設備預設只會自動下載更新，不會自動安裝。請到 Live Update 確認狀態是「Currently Installed」。 設定步驟 1
  2. 確認每個 PHP 網站的 policy 都包含這 3 個 signature 其中 2 個不在常用的預設 signature set 裡，需要另外加入 policy。 設定步驟 2、3
  3. 把 3 個 signature 設為 Enforced，並 Apply Policy 新加入的 signature 預設在 staging 狀態，只會記錄、不會阻擋。 設定步驟 4
  4. 驗證防禦已生效 用瀏覽器開啟測試頁並送出，確認 WAF 回應阻擋頁。不需要另外寫程式。 驗證方法

BIG-IP 設備本身

BIG-IP 的管理介面（Configuration utility）也使用 PHP。F5 公告 17.1.0–17.1.3、17.5.0–17.5.1、21.1.0 受影響，需要已登入的管理帳號才能利用，目前尚無修正版。F5 建議調整 BIG-IP 上的 PHP 設定，並把管理介面限制在可信任的網段與帳號。

BIG-IQ、F5OS、NGINX 全系列與 F5 Distributed Cloud 不受影響。
