設定步驟：讓 3 個 php2shell signature 生效

共 4 個步驟。步驟 1 每台設備做一次，步驟 2 到 4 每個保護 PHP 網站的 policy 都要做。畫面取自 BIG-IP 17.5.1.8。

開始前

  • 確認保護 PHP 網站的 policy 是 Blocking 模式。Transparent 模式只記錄、不阻擋。
  • 備份要修改的 policy（Export 或 UCS）。
  • 建議在維護時段操作。Apply Policy 不會中斷連線，但新規則可能誤擋正常流量。

步驟 1　安裝特徵碼更新（ASU）

GUI 路徑System ›› Software Management : Live Update ›› ASM Attack Signatures

找到 ASM-AttackSignatures_20261022_154742.im（或更新版本），看 Status 欄位。下面的畫面是較早的 20261021_191526，操作方式相同。

Status意思
Currently Installed已安裝，做步驟 2
Pending (Preview Available)已下載，但沒有安裝
清單中沒有按 Check for Updates；設備不能連網時，從 MyF5 Downloads 下載後按 Upload File

點選檔名，按 View Full Readme 可確認含有 200204113、200103697、200204115。確認後按 Install，等 Status 變成 Currently Installed（實測約 3 分 30 秒）。

確認設備上已有 3 個 signature

GUI 路徑Security ›› Options : Application Security : Attack Signatures : Attack Signatures List

按漏斗圖示，在 Attack Signature Name 輸入「PHP Remote Code Execution」，按 Apply。

步驟 2　確認 policy 是否包含 3 個 signature

GUI 路徑Security ›› Application Security : Security Policies : Policies List ›› （policy 名稱）›› Attack Signatures

按漏斗圖示，在 Attack Signature Name 輸入「PHP Remote Code Execution」，按 Apply。

搜尋結果下一步
3 筆都在，Status 都是 EnforcedApply Policy 後，做驗證
3 筆都在，但 Status 是 Staging做步驟 4
少於 3 筆，或沒有資料做步驟 3，再做步驟 4

為什麼會沒有

policy 只使用已指派的 signature set。這 3 個 signature 屬於 PHP 系統，而且其中 2 個 accuracy 是 Low，常用的「Generic Detection Signatures (High/Medium Accuracy)」不包含它們。

在 policy 加入 Server Technology「PHP」時，GUI 會建立「PHP Signatures (High/Medium Accuracy)」：

只加 Server Technology PHP 不夠200103697 與 200204115 仍然不會進入 policy。請用步驟 3 的專用 signature set。

步驟 3　建立專用 signature set 並指派給 policy

3-1　建立 signature set（每台設備一次）

GUI 路徑Security ›› Options : Application Security : Attack Signatures : Attack Signature Sets ›› Create
欄位設定值
Attack Signature Set Namephp2shell_CVE-2026-109618_109619
Default Blocking ActionsLearn、Alarm、Block 都勾選
Assign Set to Newly Created PoliciesNever
Signature Set TypeManual
  1. 在 Signature Name or ID 輸入「PHP Remote Code Execution」。
  2. 把滑鼠移到 PHP Remote Code Execution、(2)、(3) 這 3 筆上，按右側的「+」。不要加入 Juniper JunOS 那一筆。
  3. 確認 Assigned Signatures 顯示 (3)，按 Add。

3-2　指派給 policy（每個 PHP policy 都要做）

GUI 路徑Security ›› Application Security : Policy Building : Learning and Blocking Settings ›› Attack Signatures
  1. 在頁面上方選擇 policy，展開 Attack Signatures，按 Change...。
  2. 勾選 php2shell_CVE-2026-109618_109619，按 Change。
  3. 確認新 set 的 Learn、Alarm、Block 都已勾選，按 Save。

步驟 4　Enforce 並 Apply Policy

新加入 policy 的 signature 一律先進 staging。staging 期間（預設 7 天）只記錄、不阻擋，所以要手動 Enforce。

GUI 路徑Security ›› Application Security : Security Policies : Policies List ›› （policy 名稱）›› Attack Signatures
  1. 按漏斗圖示，搜尋「PHP Remote Code Execution」。
  2. 勾選 200204113、200103697、200204115，按 Enforce，在確認視窗再按 Enforce。
  1. 按右上角 Apply Policy，在確認視窗按 OK。「Changes details (not applied)」消失就完成（實測約 10 秒）。
多個 policy每個保護 PHP 網站的 policy 都要做步驟 2 到 4。BIG-IP 上可執行 唯讀檢查 script，一次列出所有 policy 的狀態。
設定完成後，請確認防禦已生效。下一步：驗證方法
